# 08. 국내 — 경비 SaaS(비즈플레이·고위드·더존) / 카드사 통제 / 클린카드 / 공공 감사

> 조사일 2026-11-02. 출처 등급: [공식문서] [정부지침] [감사보고서] [마케팅] [2차]. 확인 못 한 항목은 ⚠️ 표기.
> 전제: 국내 SaaS 3사는 **탐지 알고리즘·룰 목록·정확도를 공개한 문서가 한 건도 없다.** 아래 "메커니즘"은 공식 도움말(docs.bizplay.co.kr, 고위드 채널톡 가이드)과 홍보 기사에서 추출한 것이고, 그 외는 전부 마케팅이다. 반면 공공 부문(클린카드·업무추진비 지침·감사결과)은 1차 자료가 풍부해 이 문서의 실질 가치는 거기에 있다.

## 0. 한 장 요약

국내 법인카드 통제는 세 층으로 나뉜다. (a) 카드사 승인 단계에서 업종을 막는 **클린카드**(정부 2005~, 민간은 BC "클린 서비스"), (b) 카드사 EDI로 승인내역을 받아 용도 입력·지출결의로 흘려보내는 **회계형 SaaS**(비즈플레이·고위드·더존), (c) 기재부 지침의 23시·휴일·50만원·분할 기준으로 사람이 뒤지는 **감사**. 셋 중 어디에도 "룰 + 증거 + 판정 피드백"을 가진 윤리경영팀용 사후 검토 제품은 없다.

- **클린카드는 업종코드 사전 차단이다.** 기관이 카드사에 업종번호 목록을 메일로 보내면 그 업종의 가맹점 승인이 거절된다. 의무 제한 업소는 유흥·기타주점·위생·레저·사행·기타 6군 40여 개(2011 권익위 권고 기준). 가맹점이 "일반음식점"으로 위장 등록하면 무력화되고, 이는 국세청 위장가맹점 적발(연 1,200~1,600명)로 상시 확인된다.
- **감사가 실제로 돌리는 테스트는 6개로 수렴한다.** 제한업종 · 23시 이후 · 공휴일/토·일 · 50만원 회피 분할결제(동일 장소 5분 내) · 근무지 외 지역 · 상품권 등 유가증권 구입. 2010년 109개 공공기관 특별감사, 2024년 산업부 감사(분할 73·상품권 46·휴일 65 = 184건)가 모두 이 묶음이다.
- **SaaS가 확인되는 메커니즘은 입력·수집에 그친다.** 비즈플레이는 17개 카드사 EDI, 10개사 실시간 승인(하나카드는 30분 배치), 필수 항목 미입력 시 지출결의 차단, "휴일·심야·근무 외 지역·제한업종·동일 가맹점 중복"을 한 화면에 표시(2017 홍보 기사). 점수·우선순위·판정 저장은 어디에도 없다.
- **공개 서식이 이미 표준이다.** 지자체·공공기관 업무추진비 공개는 일시·장소·목적·대상(인원)·금액·결제방법·비목 7~8열로 수렴한다. 우리 요약 리포트의 기본 열로 그대로 쓸 수 있다.
- 가져올 것: 클린카드 업종 목록을 룰 파라미터로, 감사 6종 테스트를 룰 후보로, 공개 서식을 리포트 형태로. 피할 것: 가맹점 업종코드 단독 의존(위장가맹점), 사전 차단만으로 끝났다고 보는 것(2005년 도입 후 2011·2024년에도 같은 위반이 반복).

## 1. 한 줄 정의

- **비즈플레이(웹케시 계열)**: 카드사 EDI로 법인카드 승인·매입 데이터를 받아 직원이 모바일에서 용도를 붙이고 관리자가 지출결의·ERP로 넘기는 **경비지출관리 SaaS**. 카드사 공동 브랜드(우리카드 비즈플레이, 현대카드 비즈플레이, KT 비즈플레이)로도 유통. [공식문서][마케팅]
- **고위드(gowid)**: BC·신한·롯데·KB 등 제휴 카드사 명의로 스타트업 법인카드를 발급하고, 결제 내역을 앱에서 실시간 확인, 영수증 제출 마감 푸시, 더존 WEHAGO/Amaranth/i-CUBE 업로드 양식을 월별 생성하는 **카드 발급 + 지출관리**. [공식문서]
- **더존 WEHAGO / Amaranth 10**: ERP·그룹웨어. 카드 승인내역을 전표로 바꾸는 "자동전표"가 중심이고, 확인되는 실시간 이상거래 탐지는 **자금거래(이체)** 대상이다. 법인카드 부정사용 탐지 기능은 공식 자료에서 ⚠️ 미확인. [마케팅][2차]
- **이카운트·스마트빌**: 카드 내역을 조회해 거래처 코드를 수동 매핑하는 수준이라는 경쟁사 블로그 서술만 있음 ⚠️. 본 문서에서는 다루지 않는다. [2차]
- **클린카드(정부)**: 기재부 『예산 및 기금운용계획 집행지침』(2006~)과 권익위 권고(2007.10, 2011.10)로 업무추진비 카드를 **카드사 업종 차단**이 걸린 카드로만 쓰게 한 제도. 민간 카드사는 같은 기능을 "업종 제한(클린 서비스)" 부가서비스로 판다. [정부지침][공식문서]

## 3. 구성요소와 흐름

```
 [사전]  카드사 승인 서버 ── 업종번호 블랙리스트(클린카드/클린 서비스) ──▶ 승인 거절 "거래제한 업종"
                              └ 기관 회계담당자가 메일로 업종번호+카드번호 목록 송부 (BC: bcin@)
 [수집]  카드사 EDI/직접 ──▶ SaaS 승인내역 ──▶ 직원 앱: 용도·내용·동료명·코스트센터 입력 (+영수증 사진)
                                              └ 필수항목 미입력 → 지출결의 차단 (비즈플레이)
 [회계]  관리자 화면: 월별·부서별 집계, "휴일·심야·근무 외 지역·제한업종·동일가맹점 중복" 표시
         ──▶ 지출결의 ──▶ ERP 전표(더존 양식 업로드 / 데이터중계)
 [감사]  내부감사·상위기관·감사원·의원실: 엑셀로 23시/휴일/50만원 분할/제한업종/유가증권 필터 → 소명서 요구 → 환수·징계
 [공개]  기관장·임원 업무추진비 월별 공개(알리오·클린아이·홈페이지) → 언론·시민단체 재분석
```

세 층은 서로 연결돼 있지 않다. 승인 차단 결과는 SaaS에 남지 않고(거절 거래는 승인내역이 아님), SaaS의 표시 항목은 감사 결과로 돌아오지 않으며, 감사의 소명·환수 결정은 어디에도 구조화 저장되지 않는다.

## 4. 판단 방식

- **클린카드 메커니즘** [공식문서 BC/고위드 가이드]: 업종은 "가맹점의 상위 개념"이고 **상위 업종을 제한하면 하위 가맹점 전체 승인이 거절**된다. 적용 단위는 **사업자번호**(법인 전체) 또는 지정 카드번호. 요청은 카드사 회계담당자 메일 1통(업종번호·업종명·카드번호 첨부)이며 셀프서비스 UI는 없다. 승인시간 제한 가능 여부는 BC 문서에 없음 ⚠️. 코나비즈 카드는 업종·요일·시간대·건당/일 한도·일 횟수 제한을 관리자 UI로 제공한다고 안내(지역 제한·알림은 없음). 신한카드는 "업종 제한(클린 서비스) 설정" 부가서비스가 공지 목록에 있으나 상세 ⚠️, 삼성·현대는 공개 자료 없음 ⚠️, KB국민 "카드사용안심서비스"는 개인회원 전용(기업카드 제외). 신한은행 CMS 법인카드 통합관리는 "사용가능 시간·지역 지정"을 광고하나 카드사 기능과 동일한지 ⚠️. [마케팅]
- **의무적 제한 업소(권익위 2007.10/2011.10 권고 → 기관 지침에 복제)** [정부지침, KOCCA 2026-07-21 개정본에서 전사]:
  - 유흥: 룸살롱·단란주점·나이트클럽·유흥주점·맥주홀·칵테일바·스넥칵테일·주류판매점·카페·캬바레·요정·한국식/서양식 접객주점·무도유흥주점·극장식 주점
  - 기타주점: 소주방·호프집·막걸리집·토속주점
  - 위생: 이·미용실·피부미용실·사우나·안마시술소·스포츠마사지·네일아트·지압원·발마사지 등 대인서비스
  - 레저: 실내외 골프장·노래방·사교춤·전화방·비디오방·골프연습장·스크린골프·당구장·헬스클럽·PC방·스키장
  - 사행: 카지노·복권방·오락실 / 기타: 성인용품점·총포류
  - 구매 제한 물품(업종이 아니라 품목): 귀금속·고가 주류·골프용품·건강보조식품·고급 화장품/액세서리 — **업종코드로는 못 잡고 영수증 품목으로만 잡힌다**.
  - 연혁: 2011 지침 18개 명시 → 2012 지침 19→32개(스크린골프·당구장·헬스클럽·PC방·스키장 등 13개 추가) → 지자체 "의무 8종~17종"(경남도 감사 2022). **현행 기재부 지침 원문은 검색으로 미확보** ⚠️. 기관별 지침은 권익위 권고를 복사하되 자율 추가 업종이 달라 목록이 기관마다 다르다.
- **시간·금액 규칙** [정부지침 KOCCA 제3조⑤·제5조③④]: 집행시간 근무일 06~23시. 공휴일·토·일, 근무지·회의장소와 무관한 지역, 23시 이후는 "법인카드(공휴일, 심야) 사용 소명 신청서"(일시·장소·목적·집행대상·업무내용·사유, 자필서명) 승인 필요. **건당 50만원 이상은 주된 상대방 소속·성명 기재** — 이 50만원이 분할결제의 동기다. 정산 10일(해외 30일). 상품권·화환은 구매·배부 대장 관리. 소명 안 되면 불인정·환수(제6조).
- **감사의 판단**: 룰 적중 → 소명서 → 사람이 "직무관련성 입증" 여부 판단. 점수·확신도 개념 없음. 경남도 감사의 거창군 심야 1건(23:11 연극제 후 직원 간식)처럼 **적중 = 위반이 아니다**가 기본값이고, 소명으로 종결된다. [감사보고서][2차]
- **SaaS의 판단**: 비즈플레이는 위 항목을 "한눈에 감시"할 **표시 열**로 제공하며 환경설정으로 "주말 사용 불가·심야 제한" 등 회사 규정을 설정할 수 있다고 홍보. 점수화·우선순위·자동 플래그 여부 ⚠️. 고위드는 한도(카드/청구/일/횟수)와 영수증 마감 푸시만 확인. 더존은 카드 관련 판단 로직 자료 없음. [마케팅][공식문서]

## 5. 피드백

- **SaaS**: 관리자 판정(위반/정상)을 저장하거나 룰에 되먹이는 기능은 3사 모두 공식 문서에 없다 ⚠️. 비즈플레이의 "필수항목 미입력 시 결의 차단"이 유일한 강제이고, 이는 입력 단계의 통제다.
- **클린카드**: 피드백 경로가 **지침 개정**이다. 2011 권익위 권고(16→확대, 구매제한 물품, 월별 공개, 감사담당자 통보, 실시간 감시 시스템 권고) → 2012 지침 32개. 가맹점 단위 학습은 없다. 권익위가 2011년에 "결제 즉시 금지업종·심야·휴일·분할결제를 확인하는 실시간 IT 시스템을 1만 1,527개 기관이 운영"하라고 권고했는데, 그 시스템이 실제 구축됐다는 자료는 찾지 못했다 ⚠️. [정부지침][2차]
- **감사**: 처분(환수·징계·주의) 코드는 감사결과서에 있지만(산업부: 중징계 1·경징계 2·주의경고 35건·환수 약 200만원·권고 3·통보 6), 거래 단위로 "소명 인정/불인정" 라벨이 축적되는 저장소는 없다. [감사보고서]

## 7. 구조적 한계

1. **업종코드 사전 차단은 코드가 정직할 때만 작동한다.** 위장가맹점(일반음식점·모텔·복지단체 명의 단말기)은 국세청이 연 1,200명 이상 적발하는 상시 현상이고, 거창군처럼 의무 업종 0건이어도 권고 업종(민속주점·맥주전문점)으로 위반이 이동한다. 구매제한 물품(양주·골프용품)은 업종으로 잡히지 않는다.
2. **시간·금액 임계값은 알려져 있어 바로 앞에서 멈춘다.** 50만원 상대방 기재 → 49만원대 분할, 23시 → 22시대 결제. 선관위 분석이 22시로 내린 이유다. 임계값 단독 룰은 경계 바로 아래 군집을 봐야 의미가 있다.
3. **거절 거래는 데이터로 남지 않는다.** 클린카드가 막은 시도는 승인내역에 없어 SaaS·감사 어느 쪽도 "시도 패턴"을 볼 수 없다. 반복 시도자를 알 방법이 카드사 외에는 없다.
4. **SaaS는 회계 완결성을 보고 윤리 위반을 보지 않는다.** 확인되는 강제는 "필수항목 미입력 시 결의 차단"뿐이다. 용도 텍스트의 진위, 참석자 실재, 동일 상대방 반복은 검증 대상이 아니다. 홈택스 분류도 부가세 공제 관점이다.
5. **판정이 저장되지 않는다.** 소명서는 종이·결재 문서로 끝나고, 거래 단위 "소명 인정/불인정" 라벨이 없어 룰 조정·반복자 추적·정확도 측정이 불가능하다. 산업부 184건의 소명 결과도 보고서에 없다.
6. **감사는 제보·주기 의존이다.** 산업부 감사는 익명제보로 시작했고 2011년 특별감사는 권익위 조사 뒤 기재부 지시였다. 상시 100% 검토 구조가 아니다.
7. **입력이 연동 전제다.** 승인내역 엑셀을 올려 분석하는 경로가 3사 어디에도 문서화되지 않았다. 이미 다른 ERP·카드사 포털에서 엑셀을 받는 윤리경영팀에는 진입 장벽이다.

## 8. 우리에게 주는 것

### 8.1 가져올 것
- **룰 파라미터 = 클린카드 업종 목록 6군 + 구매제한 물품 5종** (`rules/thresholds.yaml`에 "의무/권고" 두 등급으로). 기관마다 자율 추가 업종이 다르므로 목록은 설정값이지 코드가 아니다.
- **룰 후보 = 감사 테스트 6종**: ① 제한업종(의무/권고 분리) ② 23시 이후(+22~23시 경계 군집) ③ 공휴일·토·일 ④ 분할결제: 동일 가맹점·**5분 내**·합산 50만원 이상 또는 동일 상대방 다중 카드 ⑤ 근무지 외 지역(동일 카드 단시간 다지역 포함) ⑥ 유가증권·상품권·귀금속·고가주류 품목. 각 룰은 소명서 항목(일시·장소·목적·대상·사유)을 증거 요구 목록으로 가진다.
- **요약 리포트 열 = 공개 서식**: 사용자/부서 · 일시 · 장소(가맹점) · 목적 · 대상(인원) · 금액 · 결제방법 · 비목. 알리오·클린아이·서울시 공개 열과 동일하게 맞추면 윤리경영팀이 그대로 외부 공개·보고에 쓸 수 있다.
- **조치 코드 = 감사결과서 처분 분류**: 환수 / 중징계 / 경징계 / 주의·경고 / 권고 / 통보 — 03 Oversight의 11코드와 합쳐 국내 용어로 정리.
- **홈택스·적격증빙은 보조 피처**: 적격증빙 없음(간이영수증·계좌이체)과 개인카드 혼용은 세법상 손금불산입 사유이므로 "증빙 결여" 룰로 추가 가능. 2026 세제개편안은 기준을 3만→5만원으로 올리는 정부안(시행령 확정 여부 ⚠️).

### 8.2 피할 것
- **가맹점 업종코드 단독 판정 금지.** 위장가맹점이 문서화된 현실이므로 업종 룰은 가맹점명 키워드(주점·바·노래·마사지)·시간대·금액 분포와 교차해야 한다. 코드가 "일반음식점"이고 23:30·1인당 20만원이면 업종코드보다 패턴을 믿는다.
- **임계값을 하나로 두지 않는다.** 50만원·23시는 회피 지점이다. 경계 바로 아래 구간(45~50만원, 22~23시)의 빈도를 사용자 단위로 집계한다.
- **사전 차단 결과를 "해결됨"으로 보지 않는다.** 클린카드 20년 뒤에도 같은 위반이 반복됐다. 우리 제품은 차단이 아니라 사후 검토이므로 "차단된 시도"가 데이터에 없다는 점을 요약 화면에 명시한다.
- **입력을 EDI 연동에만 묶지 않는다.** 카드사 포털·ERP에서 받은 엑셀 적재를 1급 경로로 유지(03·07 문서와 동일 결론).
