# 05. 미국 정부 감사보고서 — 룰 기반 탐지의 실측 성적표 (GAO · OIG · TIGTA · OMB A-123 App. B)

> 여기서 "제품"은 벤더 소프트웨어가 아니라 **감사기관이 P-card(구매카드)·travel card 데이터에 적용한 감사 방법론 자체**다. 미 연방정부는 2001년부터 25년간 같은 룰(쪼개기·주말·금지 MCC·중복·출장 아닌데 결제)을 돌리고 결과를 숫자로 공개해 왔다. 벤더 자가 보고가 아닌 **제3자 실측치가 존재하는 유일한 영역**이라 우리 설계의 기준선(baseline)으로 쓴다.

## 0. 한 장 요약

미 연방 구매카드(연 $17B+, 2006)·여행카드 프로그램을 GAO와 각 부처 감찰관(OIG)이 2001년부터 매년 감사한다. 방법은 항상 같다: **① 무작위 통계 표본으로 통제 실패율 추정 → ② 데이터 마이닝(룰)으로 의심 거래 추출 → ③ 서류 요청·면담으로 확정**. 그 결과가 룰 기반 탐지의 가장 정직한 성적표다.

- **룰 플래그의 확정률은 낮고 25년간 안정적이다.** 쪼개기 룰 10~28%(TIGTA 37/368, SSA 20/72), 주말 룰 1~31%, 벤더/MCC 룰 0~47%(미지원 서류 포함 시). CIGIE 2017 전정부 프로젝트에서는 USPS·DOI 표본 100건씩에서 **부정·부적정 0건**(서류 미비만 19~22%).
- **무작위 표본이 데이터 마이닝보다 많이 잡는다.** DoD IG 2018: PCOLS 데이터 마이닝이 플래그한 31만 건 중 무효 판정 0.14%, 반면 룰 없이 뽑은 통계 표본의 무효율 0.34%. "룰이 무작위 추출의 절반도 못 잡는다"가 공식 결론.
- **병목은 탐지가 아니라 검토다.** GSA FY2015 플래그 945건 중 28%는 아무 응답 없음, DOI 2021 IntelliLink 플래그 3건은 서류 없이 종결, SSA는 "인력 부족으로 검토 불가", DoD는 "플래그 일부가 기간 내 미검토"(각주로 인정).
- **확정 기준은 서류다.** 모든 보고서가 "서류 없으면 questionable", "원 서류 없이 판단 불가"(GAO-17-276 각주 34)라고 쓴다. 카드 데이터만으로는 플래그까지만 간다.
- 가져올 것: **무작위 표본을 분모로 삼는 정확도 보고**, 룰별 확정률 추적, 플래그 종결 SLA(GSA 30일·Army 15/30일), "indicators"(지표)라는 조심스러운 어휘, 확정 위반만 보고하는 A-123 App. B §5.3.3의 정의.

## 1. 한 줄 정의

연방 감사기관(GAO, 각 부처 OIG, TIGTA, DoD IG)이 **Charge Card Abuse Prevention Act 2012(Pub. L. 112-194)** 와 **OMB Circular A-123 Appendix B**에 따라 구매·여행카드 거래를 **룰(데이터 마이닝) + 통계 표본 + 서류 검토**로 감사하고, 플래그→표본→확정의 숫자를 공개하는 반복 절차. 산출물은 "fraudulent / improper / abusive / questionable" 분류와 기관 통제 개선 권고다. [정부보고서][공식문서]

## 2. 데이터 입력

- **소스**: 발급 은행(US Bank, Citibank, JP Morgan, Bank of America — GSA SmartPay 계약)의 **거래 레벨 추출 파일**. 필드는 카드소유자, 승인자(AO), 거래일·게시일, 가맹점명, **MCC**, 금액, 계정 상태. GAO-08-333은 FY2006 1,600만 건·$14B 전수를 받았고, SSA OIG는 FY2014 146,481건·$60.5M 전수를 받았다. [정부보고서]
- **보조 소스**: 여행카드 감사는 **출장 명령/정산 시스템(DTS)** 과 매칭해 "출장 중이 아닌데 결제"를 만든다(DODIG-2015-125는 VICM + Citibank EAS + DTS 3개를 결합). 인사 시스템과 매칭해 "퇴직자 계정 활성"을 만든다(SSA, VHA). [정부보고서]
- **전처리**: SSA는 $0.01~$10 소액 4,568건과 -$10 이하 크레딧 431건을 제거, 주말 룰에서 비내구재·서비스 거래를 제외. DoD IG는 카지노 거래 $3.2M에서 공무 출장 중 호텔 결제 등을 제거해 $952K로 축소. [정부보고서]
- **없으면 못 돌아가는 전제**: 거래 데이터에 **영수증·승인서가 없다**. 모든 확정은 기관에 서류를 요청해야 한다. DOI OIG 2021: "IntelliLink에는 구매 거래의 증빙 서류가 없어 상세 분석이 제한됐다." GAO-17-276 각주 34: "기관에 서류를 요청하지 않고는 부적정 여부를 최종 판단하기 어렵다." [정부보고서]

## 3. 구성요소와 흐름

```
 은행 거래 추출(전수)  +  출장/인사/조달 시스템
          │
          ▼
 ┌─────────────────────┐  A. 통계 표본(simple random / stratified, n=96~300)
 │ 표본 설계            │     → 통제 실패율 추정(승인·독립 검수·서류)
 │                     │  B. 데이터 마이닝(룰 배터리) → "indicators" 플래그
 └──────┬──────────────┘     쪼개기·주말/휴일·금지/의심 MCC·중복·마이너스·
        │                    연말 몰아쓰기·소유자=승인자·퇴직자 활성·한도 초과·
        │                    제3자 결제(PayPal/Amazon)·세금 포함·출장 아닌데 결제
        ▼
 ┌─────────────────────┐  플래그 수천 건 → 가중/상위 25% → 비통계 표본 수십~수백 건
 │ 서류 요청·면담       │  기관·카드소유자에게 영수증·승인서·검수 기록 요청
 └──────┬──────────────┘
        ▼
 분류: fraudulent / improper / abusive(wasteful) / questionable(unsupported) / proper
        ▼
 권고(통제 개선) → 기관 답변 → 후속 감사(follow-up) → OMB 반기 위반 보고(A-123 B §5.3.3)
```

- **A와 B는 분리된 두 경로**다. A는 모집단 전체로 외삽 가능(95% CI 보고), B는 외삽 불가. GAO는 매 보고서에 "우리 작업은 부정·부적정의 **전체 규모를 측정하도록 설계되지 않았다**"를 명시한다. [정부보고서]
- **CIGIE 2017 전정부 프로젝트**(USDA OIG 주도, 23개 OIG 참여): 공통 **9개 알고리즘**(주말/휴일, 금지·의심 MCC, 세금 포함, 제3자 벤더, 단일구매한도, 폐쇄 계정, 쪼개기 등)을 같은 도구로 돌리고, 알고리즘 적중 개수로 가중해 **상위 25%** 에서 표본을 뽑는 표준 설계. 표본 크기는 "모집단 26,302, 95% 신뢰, 오류율 <10% 가정, 허용 상한 20%" 같은 식으로 CIGIE가 지정. [정부보고서 DOI 2017-ER-015, SSA A-13-17-50266, USPS FT-AR-18-001]
- **DoD 상시 데이터 마이닝**: Army/AF/Defense agencies는 PCOLS Data Mining 모듈(이후 IOD로 교체), Navy는 Citibank PAT, 여행카드는 Visa IntelliLink(VICM). 룰이 깨지면 케이스가 생성돼 AO/APC에 배정된다(03_Oversight.md §3의 AFARS 11-4 참조). [정부보고서 DODIG-2018-101]

## 4. 판단 방식 — 플래그가 어떻게 "improper"가 되나

- **어휘**: GAO는 플래그를 "**indicators** of improper or potentially fraudulent purchases"라고만 부른다. 분류 정의(A-123 App. B 준용): *fraudulent* = 개인 용도의 무단 사용·도난/탈취 카드·미탐지 부정 활동, *improper* = 법·계약·행정 요건상 하지 말았어야 하거나 금액이 틀린 구매, *abusive/wasteful* = 합법이나 과도·불필요, *questionable* = **서류로 입증 못 함**. [정부보고서 GAO-17-276][공식문서]
- **확정 절차**: 플래그 → 서류 요청 → (서류 없음 = questionable) → (서류 있음 + 사유 타당 = proper) → (개인 용도·규정 위반 입증 = improper/fraudulent). GAO-17-276의 HUD REAC 사례: 카드소유자명 ≈ 가맹점명이라 의심했으나, 면담 결과 검사원 지급 방식으로 판명 → proper. **면담 없이는 못 닫는 플래그가 있다.** [정부보고서]
- **쪼개기 룰 정의의 차이**(윈도·임계): GAO-03-489 같은 날·같은 벤더 >$2,500; SSA 같은 카드소유자·같은 날·같은 벤더 >$3,000; DOI 2021은 3일·5일 윈도 + 같은 부서 복수 카드소유자 + 동일 금액 클러스터; TIGTA는 $3,000 한도. **같은 이름의 룰이 보고서마다 다르다**는 점이 수치 비교 시 주의점. [정부보고서]
- **사람 개입 지점**: 룰은 후보만 만든다. 확정은 감사인(서류·면담)이, 조치는 기관(AO/APC)이 한다. 기관 쪽 확정은 **AO의 월 명세 검토**가 1차 통제인데, 이 통제 자체의 실패율이 15~86%(§6)다.

## 5. 피드백 — 권고가 어디로 돌아가나

- **권고 → 기관 통제**: 권고 대상은 거의 항상 **통제 설계**(승인 전 서류, 독립 검수, 관리 범위(span of control) 1:7, 퇴직자 계정 자동 해지, MCC 차단, 교육)이지 **룰 개선이 아니다**. GAO-08-333 13개, GAO-03-292 38개, DOI 2017-ER-015 5개 권고 모두 통제 항목. [정부보고서]
- **룰로 되돌아간 사례**: DODIG-2018-101이 유일하게 "DM 테스트를 PCOLS 도입 후 한 번도 검토·개선하지 않았다"고 지적하고, **"검토 완료 거래의 월간 통계적 표본으로 검토자 결론의 정확성을 검증하라"** 고 권고(A.1.c). DPAP은 "룰의 효과성"으로 답해 "검토자 결론의 정확성"이라는 요구를 비켜갔고, IG는 미해결로 남겼다. DODIG-2025-060은 VICM 룰 갱신·고위험 가맹점(Everi 등) 자동 케이스 생성·분기별 종결 케이스 재검토 등 15개 권고. ⚠️ 본문 미열람(media.defense.gov 접근 거부), 요약 페이지만 확인. [정부보고서]
- **TIGTA 2025-308-022**(IRS 조사 선정 AI, `research_notes/tigta_2025_308_022_ai_case_selection.md`): 같은 결론을 모델 쪽에 적용. 조사 결과(Form 4549-A)가 있는데도 모델에 되먹이지 않음 → "모델이 제안하지 않았는데 조사관이 추가해 생산적이었던 쟁점을 모델이 배우게 하라", "이전 방식(DIF) 대비 개선을 증명하라". DIF는 NRP **무작위 표본 조사**로 학습·검증됨. 카드 감사와 세무 감사 모두 "무작위 표본이 모델/룰 검증의 근거"라는 점에서 일치. [정부보고서]
- **보고 의무(A-123 App. B §5.3.3)**: 연 구매카드 지출 $10M 초과 기관은 기관+IG 공동으로 **"검토 완료 후 확정된(confirmed) 위반"** 과 인사 조치를 OMB에 반기 보고. "확정 부정·손실·횡령으로 이어지지 않은 행정·내부통제 불일치는 보고 대상 아님". 즉 공식 지표는 **플래그 수가 아니라 확정 수**다. DoD는 이 보고에서 FY2015 하반기 군별 보고 1,043건을 **47건**으로 축소 보고(DODIG-2018-101). [공식문서][정부보고서]

### 6.2 교차 관찰

- **무작위 표본 vs 데이터 마이닝 발견 비중**: GAO의 "41%(2008)·45~63%(DHS)·22%(2017) 통제 실패"는 전부 **무작위 표본**에서 나왔고 마이닝은 사례(anecdote)를 공급했다. DODIG-2018-101은 유일하게 같은 척도로 비교해 **마이닝 0.14% < 무작위 0.34%** 를 보였다. GAO-17-276은 마이닝 20건에서 0건, 무작위 300건에서 improper 5건(2%). **룰이 못 보는 위반이 있다**는 것이 측정됐다. [정부보고서]
- **팁의 기여**: GAO-08-333 부정 10건 중 명시된 출처는 내부고발 1건(USDA Forest Service, 횡령 $642K급). 나머지 사례의 출처는 미기재. "기관은 전부 미탐지(All transactions were undetected by the agency)"가 반복 문구. [정부보고서]
- **플래그 미검토·지연 종결(반복 발견)**: GSA 28% 무응답(2015) · DoD "플래그 일부 미검토"(2018, Table 1 각주) · DOI IntelliLink 3건 서류 없이 종결(2021) · DoD 통보 30명 중 22명 미조치(2016) · SSA "인력 부족"(2015) · DHS 서류 부재로 **10,339건 미감사**(2006) · Navy APC 23%가 거래 시스템에 로그인한 적 없음(2002). **25년간 같은 문장.** [정부보고서]
- **"서류 미비"가 수치를 부풀린다**: GAO-03-489 벤더 룰 47%, GAO-04-737 34%, GAO-17-276 22%는 questionable(서류 없음) 포함. 순수 improper/fraudulent만 세면 2~10%대로 내려온다. 벤더 보고서(01~03)의 "탐지율"과 비교할 때 이 분모 차이를 반드시 적을 것.

## 7. 구조적 한계

1. **룰 정밀도가 낮고 수십 년 안정적**: 쪼개기 10~28%, 주말 1~31%, MCC/벤더 0~47%(서류 미비 포함). 2003(HUD) → 2011(IRS) → 2016(SSA) → 2017(CIGIE) 사이에 개선 추세가 없다. 룰이 바뀌지 않았고(GAO-17-276은 2008 범주를 그대로 재사용), 바꿀 피드백 경로도 없다.
2. **검토 용량이 병목**: 플래그는 수천~수십만 건, 사람 검토는 수십~수백 건. 모든 보고서가 플래그를 "상위 25%", "비통계 표본"으로 잘라낸다. 그 잘라낸 나머지는 영원히 미확정이고, 기관 쪽은 28~73%가 미응답·미조치.
3. **룰로 되돌아가는 피드백 없음**: 권고는 통제(승인·검수·교육)로 가고 룰은 그대로다. DODIG-2018-101이 "DM 테스트를 한 번도 검토·개선 안 함", "검토자 결론의 정확성을 측정 안 함"을 지적하고 통계 표본 검증을 권고했으나 DPAP은 비켜갔다. TIGTA 2025도 모델에 대해 같은 지적.
4. **무작위 표본만이 편향 없는 측정**: 외삽 가능한 수치(41%, 22%, 2%, 0.34%)는 전부 무작위 표본에서 나왔고, 룰 결과는 전부 "projection 불가" 고지가 붙는다. 룰 기반 시스템은 자기 재현율(recall)을 스스로 알 수 없다.
5. **카드 데이터만으로는 플래그까지**: 확정은 영수증·승인서·면담이 필요하고, 그 서류는 카드 시스템 밖에 있다(DOI, GAO-17-276). 룰 엔진이 "확정"을 자동화할 수 없는 구조적 이유.
6. **쪼개기 정의가 보고서마다 다름**: 같은 날 vs 3·5일 윈도, $2,500 vs $3,000 vs $5,000, 단일 카드 vs 같은 부서 복수 카드. 비교 가능한 "쪼개기 룰 정밀도"라는 단일 수치는 없다.
7. **금액 중심 보고**: 모든 보고서가 $ 합계로 사례를 서술한다. 소액 반복(SSA 99.8%가 ≤$3,000)은 통계 표본 아니면 보이지 않는다 — 03_Oversight.md §7-5와 같은 결론.

### 8.2 피할 함정

- 플래그 수를 성과로 보고하지 말 것 — DoD는 31만 건 플래그해 427건을 찾았다(0.14%).
- questionable(증빙 없음)을 위반으로 합산하지 말 것 — GAO 47%/34%/22%의 대부분은 서류 문제.
- 룰 결과만으로 "탐지율"을 주장하지 말 것 — 모든 정부 보고서가 "전체 규모 측정 불가"를 명시.
- 키워드 룰을 방치하지 말 것 — GSA는 구형 게임기 이름을 검색하고 있었고, 룰 1개가 잘못 쓰여 15건 중 2건을 놓쳤다. 룰 버전·테스트 케이스 필수.
- 권고를 통제에만 보내고 룰을 안 고치는 25년 패턴을 반복하지 말 것 — 확정률이 낮은 룰은 임계 조정 또는 폐기 결정을 분기마다.
