① 적재 · 정규화

엑셀을 "규칙이 바로 읽을 수 있는 표"로 바꾸고, 원본은 건드리지 않는다

왜 이렇게

  • 데이터를 먼저 세어 봤다. 시트 8개 중 적재 가치가 있는 것 4개, 메모 3개, 빈 시트 1개. 거래 시트 69열 중 뒤 29열이 HR(휴일·휴가·출장·주소)로 이미 결합돼 있어 조인 비용이 없었다
  • 금액이 글자였다. ₩27,273. 날짜·시간도 분리. 그대로는 집계 불가
  • 취소가 두 종류였다. '카드취소' 486건은 회계용 ±쌍(합이 0, 456건이 지급수수료 "카드취소 처리")이라 실거래가 아님. 진짜 부분취소는 법인카드 음수 79건, 적요에 "부분 취소"
  • 계정 이름이 규정표와 달랐다. 거래 49종 vs 규정 42종. 괄호·공백 차이가 대부분, 사람이 결정할 건 10개
  • 거부한 대안: 엑셀에서 손으로 정리 → 다음 파일부터 재현 불가, 변경 이력 없음

② 규칙 엔진

시나리오 12개를 규칙 21개로, 징계사례 22건으로 역검증

왜 이렇게

  • 규칙이 중심인 이유. 감사 결과는 징계 근거 → 걸린 이유를 규정 조항으로 설명해야 함. LLM 판단은 같은 질문에 다른 답(이전 팀 한계), ML은 라벨 0건에서 불가
  • 국내 적발 사례가 전부 단순 규칙 패턴. 강원랜드 주말 3,593건, 가스안전공사 50만원 쪼개기 103건 — 규칙을 아무도 안 돌렸을 뿐
  • 임계치는 규정에 없다. 규정표엔 "금지 업종" 종류만 있고 "몇 분 안에 몇 번"은 없음 → 도구 설정값으로 분리, 민감도 표로 윤경팀이 확정
  • 등급을 둘로. 규정 근거 있는 규칙(🔴 13개)과 통계·가설(⚪ 8개). 업계 공통(Ramp 차단/경고, Expensify 빨강/노랑)
  • 거부한 대안: 비지도 이상탐지(저발생률에서 정밀도 9~20%, 영국 정부 경비팀이 설명성 부족으로 폐기)

③ 피처 · 라벨

거래를 "평소 대비 숫자"로 바꾸고, 규칙 투표로 임시 정답을 만든다

왜 이렇게

  • 정답이 0건. 지도학습 불가 → 약한 지도(weak supervision): 규칙들을 노이즈 있는 투표자로 보고 합의 확률을 임시 라벨로. 벤치마크(WRENCH)상 이 규모에선 학습된 라벨 모델이 다수결과 차이 없음 → 선언된 집계
  • 피처는 규칙과 분리. 정답이 규칙에서 왔는데 입력도 규칙이면 베끼기. 규칙이 못 보는 것(사용자 평소, 가맹점 희소도, 부서 비교, 거래 간격)만 입력
  • 시점 기준. 3/20 거래의 "평소"에 3/31 데이터가 들어가면 미래 누수. feature store 표준(Airbnb Chronon, Tecton)
  • 합성 79건은 학습에 안 씀. 규칙 명세에서 만든 데이터라 순환. 회귀 테스트로만
  • 거부한 대안: 합성으로 학습, 무작위 분할, prob 회귀/가중치(규칙 수 베끼기로 회귀)

④ 점수 모델

세 후보를 같은 시험에 올리고, 기준선을 이길 때만 채택한다

왜 이렇게

  • 모델은 순서만. 판정은 사람. 자동으로 바뀌는 건 검토 목록의 순서뿐 (Ramp Policy Agent도 추천만, 최종은 사람)
  • 기준선 없이는 증명 불가. 미국 국세청 감사원(TIGTA 2025-308-022) 지적 2: "AI가 이전 방식보다 나은지 평가 절차 없음". 그래서 지금 방식(규칙 수×금액 정렬)을 같은 소켓의 후보로
  • 트리 모델이 맞는 규모. 표 데이터·라벨 수천 건에선 트리가 DNN보다 우세(Grinsztajn 2022). Stripe가 DNN으로 간 조건(일 수백만 라벨, 100ms)은 우리에 없음. DNN은 빈 자리로
  • 교체 가능한 소켓. fit / predict / explain 세 함수만 지키면 어떤 모델도 꽂힘. 화면은 점수와 이유 3개만 받음
  • 시간순 분할. 1~2월 학습 → 3월 시험. 무작위 분할은 같은 사람이 양쪽에 들어가 과대평가

⑤ 검토 큐

규칙에 걸린 것 + 모델 추천 + 무작위 표본, 그리고 "왜 올라왔나"를 기록한다

왜 이렇게

  • 필터는 두 방향으로 틀린다. "잘못 잡음"은 걸린 걸 보면 저절로 드러나지만, "놓침"은 안 걸린 더미를 아무도 안 보면 영원히 모른다. 운영은 보이는 오탐만 줄이는 쪽으로 기울어 시스템이 조용해지는 것을 좋아지는 것으로 착각
  • 무작위 표본이 유일한 창문. 사람이 고르면 또 하나의 규칙. 미국 국세청의 NRP(통계적 무작위 표본 조사)가 선정 모델 검증의 근거인 것과 같은 축소판
  • 출처 기록 없이는 공정한 평가 불가. 규칙이 고른 거래의 판정으로만 모델을 채점하면 "규칙이 보여준 세계" 안의 점수. 무작위 행의 판정이 중립 시험지(Farquhar 2021 능동학습 편향)
  • 재빌드 보호. 판정이 붙은 행은 다시 뽑아도 유지 — 라벨 고아 방지
  • 거부한 대안: 페이지 로드마다 즉석 샘플(재현 불가), reservoir sample(멀티스레드에서 불안정) → hash(tx_id‖seed) 정렬
