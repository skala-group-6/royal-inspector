4 · 데이터가 알려준 것

받은 데이터를 돌려 보니

112/ 166건

실제 주점 결제 중 의욕관리비로 처리된 건. 규정상 접대비만 가능 → 윤경팀에 첫 질문

0건

정답 라벨. 규칙 21개의 투표로 임시 정답을 만드는 약한 지도로 시작, 윤경팀 판정이 오면 같은 스크립트로 교체

7%

출입기록 중 출문 비율. "나간 기록 없음"은 신호가 아님 → 카드 대여 규칙을 "입문 직후 먼 곳 결제"로

29%

초기 임계치에서 규칙에 걸리는 거래. 임계치는 규정이 아니라 도구 설정 — 우리가 초기값, 윤경팀이 확정

81%

규칙을 못 보는 XGBoost가 행동 피처만으로 규칙 합의를 복원한 정도(PR-AUC). 상위 100건은 기준선과 3%만 겹침 → 규칙 밖 탐지의 재료

100%

징계사례 22건을 심은 합성 정답셋 79건에 대한 규칙 재현율. 규칙을 고칠 때마다 자동 재채점
