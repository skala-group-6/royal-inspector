## 2. 새로 알게 된 것
- 정답 라벨 없음 → 규칙 투표(약한 지도)로 임시 정답. 한계를 문서·화면에 명시.
- 임시 정답으로는 모델이 단순 정렬을 못 이김(정답이 규칙에서 왔으므로). 규칙을 못 보는 XGBoost가 행동 피처만으로 규칙 합의 81% 복원, top-100 겹침 3% → 규칙 밖 탐지의 재료.
- 실제 주점 166건 중 112건이 의욕관리비(규정상 접대비만) → 윤경팀에 첫 질문.
- 출입기록은 입문 위주(출문 7%) → 카드 대여 규칙을 "입문 직후 비인접 시도 결제"로.
- 임계치는 규정이 아니라 도구 설정. 우리가 초기값, 윤경팀이 확정(docs/RULES.md 민감도 표).
- "혼자만 가는 가게가 수상" 가정이 약한 신호와 반대(+0.36) → 가정 제거·기록.
- 테스트 판정 4건(정민교)이 DB에 있음. reviewer 이름으로 분리되어 학습·선례 제외. 팀 전원 숙지.
