# 우선순위 모델 설계 — 2026-10-31

## 자리
모델은 플래그를 **만들지 않는다**. 규칙 엔진이 만든 플래그의 **순서를 정한다**(재정렬기). 예측 대상은 "이 플래그가 위반으로 확정될 확률".
규칙 판정, 취소 제거, OCR, 자연어 번역에는 쓰지 않는다.

## 라벨 출처 (코드가 강제)
`features.py --label-source {synthetic|reviews}` 를 반드시 명시한다. 기본값 없음.
- `synthetic`: ground_truth의 심은 위반=1, 합성 사용자의 정상 거래=0. **시연용**. 심은 패턴을 다시 찾는 모델이므로 실제 성능이 아니다.
- `reviews --reviewers 이름,이름`: 지정 검토자의 최신 결정만. violation=1, ok=0, hold 제외. 개발팀의 테스트 판정은 절대 포함하지 않는다.

## 피처 (전부 flags·tx_active에서 계산, 결과 이후 정보 금지)
규칙별 걸림 여부(19), 걸린 규칙 수, violation 등급 수, 금액, 동료 중앙값 배수, 시간대, 휴일·휴가·출장 여부, 증빙 여부, 같은 사람 과거 플래그 수, 선례 겹침 점수(있으면).
검토자 이름·검토 시각처럼 결과 이후에 생기는 정보는 넣지 않는다.

## 학습·검증
- 기준선 로지스틱 회귀, 본 모델 XGBoost. 둘 다 돌리고 기준선보다 나을 때만 XGBoost 채택.
- **시간순 분할**: 2월 학습 → 3월 검증. 무작위 분할 금지(같은 사람이 양쪽에 들어가 성능 과대).
- 지표: 상위 K건 정밀도(K = 감사자가 하루에 보는 건수), 보조로 AUC.
- 산출물: `models/<version>/model.pkl` + `manifest.json`(피처 목록, 라벨 출처, 검토자 목록, 학습 기간, 지표, 데이터 스냅샷 해시).

## 적용
`score_tx.py` → `tx_score(tx_id, score, model_version)`. 목록 정렬 옵션 "모델 점수". 점수 옆에 기여 상위 피처 3개.

## 재학습
`train.py --label-source reviews --reviewers …` 재실행. 이전 버전보다 검증 지표가 나을 때만 교체. Octave Run 스크립트로 등록.
